# سَكِينَة — Sakinah

تطبيق إسلامي شامل: **مصحف كامل أوفلاين**، أذكار وأدعية بمصادرها، مواقيت صلاة وقبلة
محسوبة على الجهاز، وِرد واستمرارية، وأسماء الله الحسنى.

## الوعد الأساسي

> **بلا إعلانات. بلا تتبّع. بلا حساب. بلا تسجيلات محميّة.**

كل شيء يعمل على جهاز المستخدم. لا خادم، ولا تحليلات، ولا معرّفات.

| المجلد | المحتوى |
|---|---|
| `data/` | البيانات المُولّدة من مصادر موثّقة + سكربتات التوليد والتحقق |

## 1) نسخة الويب (PWA)

### التشغيل محليًا

```powershell
cd web
python -m http.server 8731 --bind 127.0.0.1
# ثم افتح: http://127.0.0.1:8731/
```

> **مهم:** لا تفتح `index.html` بالنقر المزدوج (`file://`) — عامل الخدمة والتحميل
> يحتاجان خادمًا محليًا. أي خادم ساكن يعمل (Python، Node، Nginx).

### التثبيت على الموبايل

- **أندرويد (Chrome):** قائمة ⋮ ← «تثبيت التطبيق» / «إضافة إلى الشاشة الرئيسية».
- **آيفون (Safari):** زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

بعد التثبيت يفتح التطبيق في نافذة مستقلة ويعمل بالكامل بدون إنترنت.

### المزايا في نسخة الويب

- مصحف كامل: ١١٤ سورة، تصفح، بحث في النص، علامات، متابعة آخر موضع، تكرار آية للتحفيظ، ختمة.
- أذكار: ٢٦٧ ذكرًا في ١٣ تصنيفًا، عدّاد لكل ذكر، **مرجع كل ذكر معروض**.
- أدعية حسب الحالة (١٠ حالات: همّ، قلق، سفر، مرض، ذنب…).
- أسماء الله الحسنى: ٩٩ اسمًا مع المعنى والدليل والشرح والمراجع.
- مواقيت الصلاة: ١٩ طريقة حساب معتمدة + مذهبا العصر، محسوبة محليًا.
- القبلة: زاوية الدائرة الكبرى + بوصلة الجهاز (إن دعمها).
- سبحة رقمية، وِرد يومي، سلسلة استمرارية، شبكة ٣٠ يومًا.
- وضع ليلي/نهاري، أحجام خط، تصدير/استيراد نسخة احتياطية.

## 2) تطبيق Flutter (أندرويد)

المشروع كامل وجاهز للبناء. **لا يمكن بناؤه في بيئة التسليم** لعدم توفّر
Flutter SDK و Android SDK (تفاصيل في `VERIFICATION.md`).

### بناء APK على جهازك

```powershell
# ١) تأكد من توفّر Flutter
flutter doctor

# ٢) من مجلد المشروع
cd flutter_app
flutter pub get

# ٣) اختبارات الوحدة (تشمل القبلة والمواقيت)
flutter test

# ٤) بناء APK للإصدار
flutter build apk --release
# الناتج: build\app\outputs\flutter-apk\app-release.apk
```

للتثبيت المباشر على جهاز موصول:

```powershell
flutter run --release
```

### المزايا في نسخة Flutter

نفس مزايا نسخة الويب، بالإضافة إلى:

- **تنبيهات أذان وأذكار حقيقية** عبر `flutter_local_notifications`، مع إعادة
  جدولة تلقائية بعد إعادة تشغيل الجهاز.
- **بوصلة حقيقية** عبر `flutter_compass` بمستشعرات الجهاز.
- تخزين محلي أصلي عبر `shared_preferences`.

## 3) إعادة توليد البيانات

كل البيانات مُولّدة بسكربتات قابلة لإعادة التشغيل:

```powershell
# القرآن: بناء + تحقق بمصدرين مستقلّين
python data/scripts/build_quran.py

# الأذكار: بناء + فحص سلامة + دمج الفضل
python data/scripts/build_azkar.py

# الأسماء الحسنى + أدعية الحالات
python data/scripts/build_names_duas.py

# جدول المدن والقبلة
python data/scripts/prayer_engine.py

# التحقق من المواقيت مقابل AlAdhan API (يحتاج إنترنت)
python data/scripts/verify_prayer.py

# أيقونات التطبيق (مرسومة برمجيًا)
python data/scripts/make_icons.py
```

### الاختبارات

```powershell
# محرك المواقيت: JS مقابل Python (٣٨٤ حالة)
python data/scripts/tests/gen_js_cases.py
node data/scripts/tests/test_prayer_js.js

# اختبار تكامل تطبيق الويب في بيئة DOM (٤٦ فحصًا)
cd data/scripts/tests
npm install jsdom
node test_integration.js
```

## ملاحظات أمانة

1. **التخريج:** مصدر حصن المسلم الشعبي يذكر نص الذكر وعدده وفضله، لكنه لا يذكر
   رقم الحديث وكتابه لكل ذكر. لذلك كل ذكر يحمل حقل مرجع، والأذكار التي ينقصها
   تخريج مُوسَمة صراحةً بـ«يحتاج مراجعة تخريج» **ولم نُكملها من عندنا**.
   للنشر العام يُراجَع مع جهة علمية معتمدة.

2. **تراخيص الأذكار:** مصدرا الأذكار بلا ترخيص صريح. للاستخدام الشخصي مقبول،
   وللنشر العام يُفضّل مصدر مرخّص أو إذن من الجهة.

3. **الصوت:** لم نُضمّن أي تسجيل محميّ. البنية جاهزة، وتحدد أنت المصدر المسموح.
